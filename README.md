# 🗓️ 스티커 메모 캘린더 (Sticky Note Calendar)

윈도우 바탕화면에서 가볍고 편리하게 사용하는 **포스트잇 스타일의 데스크톱 스티커 메모 & 스마트 캘린더**입니다.  
**파이썬이나 도커를 설치하지 않아도 더블 클릭 한 번으로 실행되는 단일 실행 파일(`.exe`)**을 제공합니다.

---

## 🚀 가장 빠른 사용 방법 (일반 사용자 추천)

복잡한 개발 도구(Python, Docker, 가상환경 등)를 설치할 필요가 전혀 없습니다!

1. **[최신 릴리즈 페이지 (v1.0.0)](https://github.com/Jeoungeunseok/local-memo/releases/tag/v1.0.0)** 또는 **[👉 StickyCalendar.exe 바로 다운로드](https://github.com/Jeoungeunseok/local-memo/releases/download/v1.0.0/StickyCalendar.exe)**를 클릭하여 실행 파일을 다운로드합니다.
2. 다운로드한 `StickyCalendar.exe` 파일을 바탕화면 등 원하는 위치로 옮겨 **더블 클릭**하면 즉시 실행됩니다.

> 💡 **데이터 영구 보존 안내**:  
> 실행 파일(`.exe`)을 다른 폴더로 옮기거나 추후 새 버전으로 교체하더라도, 작성된 모든 메모와 할 일 데이터는 Windows 사용자 데이터 저장소(`%APPDATA%\StickyCalendar\sticky_notes.db`)에 안전하게 영구 보존됩니다.

## ✨ 핵심 기능 (Features)

### 1. 🎨 감성적인 파스텔 5색 테마
- 🟡 노랑 (`#FEF9E7`) / 🔵 파랑 (`#EBF5FB`) / 🟢 초록 (`#EAFAF1`) / 🟠 주황 (`#FBEEE6`) / 🟣 보라 (`#F4ECF7`)
- 헤더의 팔레트(`🎨`) 버튼으로 언제든 기분과 목적에 맞춰 메모 색상을 변경할 수 있습니다.

### 2. 📝 자유 메모 & 인터랙티브 체크리스트 모드 (`Ctrl+T` / `☑️`)
- 상단 헤더의 `☑️` 버튼(또는 `Ctrl+T`)을 누르면 **일반 텍스트 모드**와 **대화형 체크리스트 모드**를 자유롭게 오갈 수 있습니다.
- **클릭 체크 & 취소선**: 체크박스를 클릭하면 즉시 연회색 취소선으로 완료 표시됩니다.
- **스마트 키보드**: 내용 입력 후 `Enter`를 치면 다음 줄 체크박스가 생성되며, 빈 줄에서 `Backspace`를 누르면 자동 삭제됩니다.
- **개별 삭제 (`✕`) & 완료 항목 정리 (`🧹`)**: 특정 할 일만 `✕`로 지우거나, 하단의 `🧹 완료 항목 정리` 버튼으로 끝난 일들을 한 번에 청소할 수 있습니다.

### 3. ⏰ 한 메모 내 다중 시간 설정 & 개별 맞춤 알람
- 체크리스트 각 행마다 **개별 `⏰` 버튼**이 제공되어, 하나의 메모 안에서도 아침 회의(`09:30`), 점심 약속(`12:30`), 퇴근(`18:00`) 등 **여러 시간을 각각 지정**할 수 있습니다.
- 할 일을 입력할 때 `14:00 고객 미팅`이나 `[10:30] 주간 회의`처럼 시간을 함께 적으면 **자동으로 시간을 인식**하여 세팅합니다.

### 4. ⏳ 2단계 스마트 알림 시스템 (10분 전 사전 알림 + 정시 알림)
- 상단 벨(`🔔`) 버튼을 켜두면 약속 시간에 늦지 않도록 **2단계로 똑똑하게 알림**을 보냅니다:
  - **10분 전 사전 알림 (`⏳`)**: 부드럽고 맑은 차임벨(`도-솔`)과 함께 `⏳ [10분 전 알림] 14:00 '고객 미팅' 10분 전입니다!` 사전 안내 발송.
  - **정시 알림 (`🔔`)**: 약속 시간이 되면 시선을 끄는 알람 비프음(`시-높은미`)과 함께 `🔔 [지금 시작!] 14:00 '고객 미팅' 시간입니다!` 토스트 발송.

### 5. 🚨 시각적 반짝임 3단 콤보 (절대 놓치지 않는 알림)
- 소리뿐만 아니라 시각적으로도 즉시 알아챌 수 있도록 강력한 시각 효과가 발동합니다:
  - **작업 표시줄 트레이 아이콘 반짝임**: 우측 하단 트레이 아이콘이 알람 시 빨간색/금색 경고 벨 아이콘으로 교차 점멸(`400ms`).
  - **메모 창 상단 벨 아이콘 점멸**: 전면으로 팝업된 메모의 벨 아이콘이 빨간색 경고등(`🚨`)과 황금색 벨(`🔔`)로 반짝여 어느 메모인지 즉시 식별.
  - **Windows 작업 표시줄 플래시**: 주황색 점멸로 다른 작업 중에도 알림 인지.
  - 메모나 트레이를 클릭하면 즉시 반짝임이 정지되고 정상 복원됩니다. (12초 후 자동 복구)

### 6. 📅 월간 캘린더 뷰 (독립 비모달 윈도우)
- 상단 헤더의 `📅` 버튼 또는 트레이 메뉴의 `📅 캘린더 뷰 열기`를 누르면 전체 월간 달력이 열립니다.
- **날짜별 하이라이트**: 메모나 일정이 있는 날짜는 진한 파란색 볼드로 자동 표시됩니다.
- **모든 할 일 펼쳐보기**: 날짜를 클릭하면 그날 작성된 **모든 메모와 하위 할 일 항목들(체크 여부, 지정 시간)이 빠짐없이 표시**됩니다.
- **비모달(독립 윈도우)**: 달력을 켜둔 상태에서도 메모를 자유롭게 생성, 편집, 최소화, 삭제할 수 있습니다.
- 목록의 항목을 더블 클릭하면 해당 메모 창이 즉시 화면 맨 앞으로 열립니다.

### 7. ⌨️ 글로벌 단축키 & 시스템 트레이
- **OS 전역 핫키 (어떤 프로그램을 사용 중이어도 작동)**:
  - `Alt + N`: 마우스 커서 위치에 즉시 새 포스트잇 생성
  - `Alt + M`: 화면의 모든 메모 한 번에 숨기기 / 다시 띄우기
- **창 내부 단축키**:
  - `Ctrl + N`: 새 메모 추가
  - `Ctrl + P`: 항상 위에 고정 (Pin 📌/📍)
  - `Ctrl + T`: 텍스트 ↔ 체크리스트 모드 전환
  - `Ctrl + S`: 즉시 저장
  - `Ctrl + D`: 메모 삭제
  - `Ctrl + H` 또는 `Esc`: 시스템 트레이로 최소화 (숨김)
- **트레이 우클릭 메뉴**: 새 메모 생성, 캘린더 뷰 열기, 모든 메모 토글, 화면에 바둑판식 자동 정렬(`🗂️`), 프로그램 완전 종료

## 🛠️ 개발자 및 빌드 가이드

### 1. 단일 실행 파일(`.exe`) 직접 빌드하기
소스 코드를 수정한 후 배포용 실행 파일을 다시 만들고 싶을 때는 제공된 배치 파일을 실행하기만 하면 됩니다.

```cmd
build_exe.bat
```
- Anaconda/Python 가상환경의 SQLite3 및 C 런타임 DLL 의존성을 자동으로 감지하여 `dist/StickyCalendar.exe` 단일 파일로 패키징합니다.

### 2. Python 스크립트로 직접 실행하기
```bash
# 의존성 설치
pip install PyQt6

# 데스크톱 앱 실행
python sticky_calendar.py
```

### 3. Docker 컨테이너 웹 버전으로 실행하기 (선택 사항)
웹 브라우저 환경에서 동일한 기능을 사용하고 싶을 경우:
```cmd
# Windows 원클릭 실행
start.bat

# 또는 도커 컴포즈 실행
docker compose up -d
```
- 브라우저 접속 주소: **`http://localhost:8080`**
